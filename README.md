
# E-Commerce Data Pipeline

## Project Overview

This project reads e-commerce sales data from a CSV file, processes the data using Python and Pandas, and creates a final CSV file.

## Files

* `sales.csv` — Raw sales data
* `pipeline.py` — Python data processing pipeline
* `final.csv` — Processed output data

## Technologies

* Python
* Pandas
* CSV
* Git & GitHub

## Pipeline

```text
sales.csv
    ↓
pipeline.py
    ↓
final.csv
```
